# US-smoke-ozone
Generated smoke O3 dataset in the US (2006-2023) and the replication materials

This repo includes replicated data and materials to preodcu the main figures in the paper "Wildfire smoke offsets decades of progress in reducing ozone exposure across the United States".

A preprint of the paper can be accessed:

The generated daily smoke O3 data can be downloaded here: https://doi.org/10.5281/zenodo.20346286

### NOTE: these data are preliminary and subject to change.
If you are interested in using the smoke O3 data, we recommend you to get in touch by sending an email to minghao.qiu@stonybrook.edu so we can share any updates with you if any changes are made to the data. Please contact us if you have any questions. Please cite the preprint (and any peer-reviewed publication afterwards) if this data is used in any analysis, report, and manuscript.
