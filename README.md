# US-smoke-ozone
Generated smoke O3 dataset in the US (2006-2023) and the replication materials

This repo includes replicated data and materials to preodcu the main figures in the paper "Wildfire smoke offsets decades of progress in reducing ozone exposure across the United States".

A preprint of the paper can be accessed:

The generated daily smoke O3 data can be downloaded here: https://doi.org/10.5281/zenodo.20346286
